# 🎮 2026 One Team — 우리 반 게임 만들기

영재교육원 초등발명반 학생들이 기획한 게임을 웹앱으로 만든 프로젝트입니다.

## 어떻게 실행하나요?

설치할 것이 하나도 없어요! `index.html` 파일을 브라우저로 열기만 하면 됩니다.

| 상황 | 실행 방법 | 조작 |
|------|----------|------|
| 🧪 테스트 | 컴퓨터 브라우저로 열기 | 키보드 / 마우스 |
| 🎯 실제 | 아두이노 우노Q + 모니터 | 아케이드 조종기 |

아두이노 우노Q는 인터넷이 되므로, **깃허브 페이지 주소를 브라우저에서 열면** 항상 최신 게임이 나옵니다. 파일을 옮길 필요가 없어요.

## 조작 방법

게임은 세 가지 방법으로 모두 조작할 수 있습니다.

1. **키보드** — 방향키 + 지정된 키
2. **마우스** — 클릭 / 드래그
3. **아케이드 조종기** — 방향 스틱 1개 + 버튼 8개

아케이드 조종기는 컴퓨터에 **키보드로 잡히는 경우**와 **게임패드로 잡히는 경우**가 모두 있어서, 키보드 이벤트와 Gamepad API를 둘 다 지원합니다.

### 🕹️ 조종기 점검기

`input-test.html` 을 열면 조종기의 스틱과 버튼이 컴퓨터에 **어떤 이름/번호로 잡히는지** 확인할 수 있습니다. 게임에 버튼을 연결하기 전에 먼저 확인해 보세요.

## 폴더 구조

```
index.html        게임 시작 페이지
input-test.html   조종기 점검기
css/style.css     함께 쓰는 디자인 파일
```

## 만드는 순서

뼈대 → 조작 → 규칙 → 꾸미기 순서로 조금씩 만듭니다.
